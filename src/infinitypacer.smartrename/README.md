# 智能重命名

在 Muvyo 内置重命名的基础上补三件事，规则写法沿用 MoviePilot 的智能重命名插件，原配置可以直接粘贴。

- **字段分隔符**：把所选字段内部的空白换成统一分隔符，例如 `BluRay HDR` → `BluRay.HDR`、`TrueHD 7.1 Atmos` → `TrueHD.7.1.Atmos`。
- **按分类或 TMDB 换模板**：某个二级分类或某一部作品使用单独的命名模板。
- **替换词**：在渲染后的整条相对路径上按顺序执行正则替换，例如 `DV` → `DoVi`、去掉 `.Atmos`。

插件不联网、不读写存储，也不移动文件。最终路径由 Muvyo 校验并执行整理。

> 需要支持 `naming` 能力的 Muvyo 版本，旧版本无法安装。

## 使用

1. 在 Muvyo「第三方插件 → 插件仓库」添加 `https://github.com/InfinityPacer/Muvyo-Addons`，安装「智能重命名」并启用。
2. 在插件设置里填写下面的配置项。
3. 在「配置 → 识别 & 整理 → 重命名」添加命名方案，选择本插件，先批量预览再保存。

## 配置项

| 配置项 | 说明 |
| --- | --- |
| 默认分隔符 | 替换字段内部空白的字符，默认 `.`，留空则不处理字段 |
| 分隔符适用范围 | 要处理的字段。从未保存过时默认处理 edition、effect、resourceType、videoFormat、videoCodec、audioCodec，保存为空表示不处理任何字段 |
| 自定义重命名模板 | 每行一条「二级分类名称:模板」或「TMDB编号:模板」，同时命中时以 TMDB 编号为准 |
| 自定义替换词 | 每行一条「被替换词 => 替换词」，只写被替换词表示删除 |

`#` 开头的行在模板和替换词里都会被忽略。

### 替换词示例

```
(?i)(?<=[\W_])BluRay.REMUX(?=[\W_]) => REMUX
(?i)(?<=[\W_])HDR.DV(?=[\W_]) => DoVi.HDR
(?i)(?<=[\W_])DV(?=[\W_]) => DoVi
(?i)(?<=[\W_])H264(?=[\W_]) => x264
(?i)(?<=[\W_])h265(?=[\W_]) => x265
(?i)(?<=[\W_])NF(?=[\W_]) => Netflix
(?i)(?<=[\W_])AMZN(?=[\W_]) => Amazon
(?i)\.Atmos(?=\W) =>
```

## 从 MoviePilot 迁移时的差异

- **正则**：插件运行在 JavaScript 里。开头的 `(?i)`、`(?m)`、`(?s)`，命名分组 `(?P<name>…)`，以及替换串里的 `\1`、`\g<name>` 都会自动转换。`(?x)` 这类无法等价的写法会被跳过，并在插件日志里提示。
- **集数偏移规则**：含 `<>` 与 `>>` 的规则对命名没有意义，直接忽略。
- **模板语法**：模板由 Muvyo 的受限渲染器执行，支持变量、`if/elif/else` 和 `lower`、`upper`、`title`、`trim`、`default`、`replace` 过滤器。不支持循环和其他过滤器，含这些写法的模板会被 Muvyo 拒绝。
- **片名字段**：`title`、`original_title`、`name`、`en_name` 可以改写分隔符，只影响展示名。MP 的 `en_title` 在 Muvyo 里没有，按含义改选 `en_name` 或 `original_title`，`original_name` 也不提供。
- **失败处理**：替换后的路径改掉了扩展名或季集标识等内容时，Muvyo 会让这个文件整理失败，不会悄悄回退到内置命名。
- **自定义占位符分隔符**：Muvyo 模板可以直接写 `@{{customization}}`，不再需要这一项。
